No more Screen Recording prompts after updates.

- Until now, macOS asked to allow Screen Recording again after every update, even though Desk Draw
  was still listed as allowed. Desk Draw is now signed with its own certificate, so macOS recognizes
  updated versions as the same app and keeps the permission.
- After updating to 0.6.1, macOS asks one last time. Allow Desk Draw under System Settings →
  Privacy & Security → Screen Recording, then quit and reopen it. Later updates keep the permission.

Requires macOS 14 or later on Apple Silicon. This build is signed with Desk Draw's own certificate and not notarized; macOS may require **Open Anyway** on first launch.
