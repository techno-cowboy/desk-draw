Desk Draw can now check for updates and install them with Sparkle.

- Use **Check for Updates…** in the menu bar menu, or leave automatic checks enabled.
- Choose whether to download and install updates automatically. Your choice is remembered.
- Updates wait for an active drawing session to finish before restarting the app.
- Update archives and the update feed are cryptographically signed and verified before use.

Versions 0.1.0 and 0.2.0 need one manual update to this version. Subsequent updates can be installed from the app.

Requires macOS 14 or later on Apple Silicon. This build is ad-hoc signed and not notarized; macOS may require **Open Anyway** on first launch and renewed Screen Recording permission after an update.
