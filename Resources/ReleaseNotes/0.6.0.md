Number the steps you point out.

- The new **Number** tool (**N**) places a colored dot with a number in it at each click: 1, 2, 3
  and so on. Drag before letting go to place it exactly.
- The next number is always one more than the highest number there, so removing a dot never leads to
  two with the same number. Once all dots are gone, counting starts at 1 again.
- Dots use the current color and size, and stay readable on any background and on the whiteboard.
- Like any mark, a dot can be selected, moved, resized and restyled, with undo.
- The screenshot's JSON file lists each dot's number, so an AI agent can match "step 3" to its place.

Requires macOS 14 or later on Apple Silicon. This build is ad-hoc signed and not notarized; macOS may require **Open Anyway** on first launch and renewed Screen Recording permission after an update.
