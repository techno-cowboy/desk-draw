Preview UI changes right over any app on your screen.

- **Imagine** (**I**, or click **✦ Imagine** next to a circle, rectangle or ellipse): describe what
  should change in the area you circled. A local coding agent replies with an HTML and CSS preview
  that renders in place over the app—without changing any files.
- **Works on any app**: no project folder is required. If Desk Draw finds the app's code (a
  `localhost` dev server, a local build, or a folder you pick with **Add Code…**), the agent reads
  it to match the app's real styles and components.
- **Iterate, compare, copy, or apply**: revise the preview with follow-up prompts, toggle visibility
  to compare with the app underneath, copy the handoff prompt + HTML, or optionally click **Apply
  to Code** to let the agent make the real change with one-click **Keep**, **Discard** (via git
  snapshot, keeping your own uncommitted work intact), and diff view.
- **Agent support**: works out of the box with **Claude Code** (CLI), **Antigravity** (`agy acp`),
  or any custom CLI/ACP agent under **Imagine Settings…**.

Requires macOS 14 or later on Apple Silicon. This build is signed with Desk Draw's own certificate and not notarized; macOS may require **Open Anyway** on first launch.
